# OpenZeppelin Contracts

Version: `v5.0.2`

Upstream: https://github.com/OpenZeppelin/openzeppelin-contracts

Commit: `dbb6104ce834628e473d2173bbc9d47f81a9eec3`

Only the ERC-20 implementation, its transitive Solidity imports, and the MIT license are vendored. Solidity sources are unmodified upstream files. `SHA256SUMS` records their upstream bytes. All dependencies needed to build MADToken are ordinary repository files; no package installation, submodule, or network access is needed.

To verify the vendored files, run `sha256sum --check SHA256SUMS` from this directory.
